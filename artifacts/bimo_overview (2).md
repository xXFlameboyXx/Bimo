# Bimo Robot Hub

Bimo is an always-on physical desktop AI robot built on Raspberry Pi.

## Core Subsystems
- **Face Renderer**: 3.5-inch SPI TFT LCD (ILI9486)
- **Speech Pipeline**: Whisper STT + Piper TTS
- **Tool Registry**: Phase 6 & Refinement Safe Tool System
- **Artifact Service**: Real file generation (PDF, DOCX, XLSX, TXT, MD, CSV, Images)
